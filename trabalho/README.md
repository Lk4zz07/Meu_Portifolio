4ª Atividade – Desenvolvimento de Site Responsivo com Bootstrap 5
1. Descrição do Projeto

O projeto Head Healthy consiste no desenvolvimento de um site informativo sobre saúde mental e hábitos saudáveis, com o objetivo de apresentar informações, orientações e práticas que contribuem para o bem-estar e a qualidade de vida.

O site foi desenvolvido utilizando HTML5, CSS3 e o framework Bootstrap 5, aplicando conceitos de responsividade, organização de conteúdo e navegação entre diferentes páginas.

2. Tema Escolhido

Saúde Mental e Hábitos Saudáveis

O tema foi escolhido com o propósito de destacar a importância do equilíbrio entre corpo e mente, abordando assuntos como meditação, alimentação consciente, qualidade de vida e cuidados com a saúde mental.

3. Objetivos da Atividade
Desenvolver um site responsivo utilizando HTML5, CSS3 e Bootstrap 5.
Aplicar o sistema de Grid do Bootstrap.
Criar uma barra de navegação padronizada entre as páginas.
Utilizar componentes visuais, como Cards e Carousel.
Organizar informações em tabelas e componentes interativos.
Desenvolver formulários utilizando as classes do Bootstrap.
Publicar o projeto utilizando o GitHub Pages.
4. Estrutura do Site

O projeto foi planejado com cinco páginas HTML interligadas por uma barra de navegação:

Página	Arquivo	Descrição
Início	index.html	Apresentação do projeto e destaques sobre saúde mental.
Sobre	sobre.html	Informações conceituais sobre o tema.
Galeria	galeria.html	Catálogo com práticas e hábitos saudáveis.
Dados	dados.html	Estatísticas, comparações e perguntas frequentes.
Contato	contato.html	Formulário para contato e feedback.
5. Tecnologias Utilizadas
HTML5: estruturação e organização do conteúdo.
CSS3: personalização visual do site.
Bootstrap 5: criação de layouts responsivos e componentes visuais.
JavaScript: funcionamento dos componentes interativos do Bootstrap.
Git e GitHub: versionamento e armazenamento do projeto.
GitHub Pages: publicação do site na internet.
6. Recursos do Bootstrap Aplicados

Na página inicial, foram utilizados recursos do Bootstrap 5, incluindo:

Navbar responsiva com menu de navegação.
Carousel para apresentação de destaques.
Cards para direcionar o visitante às demais páginas.
Sistema de Grid com containers, linhas e colunas.
Classes utilitárias para cores, espaçamentos, alinhamentos e responsividade.
Footer para identificação da atividade.

Também foi incluída a importação do Bootstrap por CDN, permitindo utilizar seus componentes e funcionalidades.

7. Responsividade

O projeto utiliza classes responsivas do Bootstrap para adaptar a apresentação do conteúdo a diferentes tamanhos de tela, como celulares, tablets e computadores.

O objetivo é proporcionar uma navegação organizada e acessível independentemente do dispositivo utilizado.

8. Publicação do Projeto

O projeto será armazenado em um repositório público no GitHub e publicado por meio do GitHub Pages.

A publicação permite acessar o site diretamente pelo navegador, sem necessidade de baixar os arquivos.

9. Considerações Finais

A realização desta atividade proporciona conhecimentos práticos sobre desenvolvimento Front-end, utilização do Bootstrap 5 e criação de páginas responsivas.

O desenvolvimento do Head Healthy permite aplicar conceitos de estruturação HTML, organização visual, navegação entre páginas e publicação de projetos na web.
