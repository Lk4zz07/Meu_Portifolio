Atividade – Desenvolvimento de Portfólio Pessoal em HTML5
Descrição do Projeto

Esta atividade consiste no desenvolvimento de uma página web de portfólio pessoal, utilizando exclusivamente HTML5, com o objetivo de apresentar informações pessoais, acadêmicas e profissionais de forma organizada e semântica.

O projeto foi desenvolvido com base em um código HTML inicial, posteriormente aprimorado com o auxílio de Inteligência Artificial (IA), buscando melhorar a estrutura, a organização e a semântica do documento, sem utilizar CSS ou JavaScript.

Objetivos da Atividade
Desenvolver uma página web utilizando somente HTML5.
Apresentar informações pessoais e profissionais.
Aplicar corretamente as tags semânticas do HTML.
Organizar o conteúdo em seções.
Aprimorar a estrutura do código com auxílio de Inteligência Artificial.
Compreender a importância da semântica e da acessibilidade no desenvolvimento web.
Estrutura da Página

O portfólio contém as seguintes seções:

Cabeçalho: apresentação e identificação pessoal.
Sobre Mim: informações pessoais e objetivos profissionais.
Formação Acadêmica: informações sobre cursos e instituições.
Habilidades: apresentação de Hard Skills e Soft Skills.
Experiência Profissional: descrição da experiência de trabalho.
Projetos: apresentação de projetos desenvolvidos.
Informações Rápidas: resumo de informações pessoais.
Contato: informações de contato e formulário para mensagens.
Rodapé: informações sobre o desenvolvimento da página.
Tecnologias Utilizadas
HTML5
Inteligência Artificial (IA)
Git e GitHub para versionamento e armazenamento do projeto.
Desenvolvimento

Inicialmente, foi criada uma estrutura básica de página HTML contendo informações pessoais e profissionais.

Em seguida, o código foi aprimorado com o auxílio de Inteligência Artificial, com foco na utilização adequada de elementos semânticos, como:

<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>
<address>

Esses elementos ajudam a organizar o conteúdo e facilitam a compreensão da estrutura da página pelos navegadores e tecnologias assistivas.

Resultado Esperado

Ao final da atividade, foi desenvolvida uma página de portfólio pessoal utilizando exclusivamente HTML5, apresentando informações pessoais, acadêmicas e profissionais de maneira estruturada, organizada e semanticamente adequada.
